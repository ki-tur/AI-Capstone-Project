READ ME
This is a simple calculator application built using Python and Tkinter.
It provides a graphical user interface (GUI) where users can input arithmetic expressions and get results instantly.

 Features:
1.	Performs basic arithmetic operations
2.	Displays results dynamically
3.	Handles invalid input with error messages

Requirements:
Before running the project, ensure you have:
1.	Installed Python 3.x installed
2.	A code editor like Visual Studio Code (optional)
3.	For VSscode make sure you have python extension installed

How to Run the Application:
Step 1: Download or Clone the Project and Save the Python file as:
Example: calculator.py
Step 2: Open VScode
Navigate to the folder where your file is located:
Step 3: Run the Program
 Step 4: Use the Calculator
•	Enter the values and mathematical expression (e.g., 50 *12)
•	Click Calculate
•	View the result displayed on the screen


Note:
	The GUI is created using Tkinter
	User input is captured through an input field
	The program evaluates the expression and displays the result
	This project uses eval () to compute expressions. It works for simple calculations but not safe for real-world applications, can execute unsafe code
